Floating Frame of Reference (FFRF) is a classical model for flexible multibody system dynamics. This method separates the rigid-body motion and flexible deformation under the assumption of small deformation. In this way, the flexible deformation can be easily reduced using vibration modes. This method is implemented in commercial software like ADAMS and RecurDyn, as it is easily to obtain modes’ information form MNF files. However, it is still complicated if one wants to develop his own code for flexible bodies with complex geometry. This technique document aims to discuss one possible way to achieve cheap implementation by construct shape integral of inertial only on element level.
